## What the rubrics guard against

- **Test 3** — a camera API that does not exist. Answers on both sides once invented `map.setFreeCameraOptions()` for MapLibre and the judge accepted them. The rubric now requires a real replacement by name (`icontains: calculateCameraOptions`; `calculateCameraOptionsFromCameraLngLatAltRotation` with `jumpTo`/`easeTo`/`flyTo`) and forbids each invented claim, checked against [`src/ui/map.ts`](https://github.com/maplibre/maplibre-gl-js/blob/main/src/ui/map.ts). A `not-icontains: setFreeCameraOptions` tripwire would fail correct answers, which name the method to say it is absent, so the rubric carries the must-not.
- **Test 7** — the negative must score the positive. "Does not bring up library migration" failed an answer that stayed on Mapbox GL JS v2 and merely noted a token-free geocoder also works with MapLibre. The rubric now asks for a geocoder that works with the app as it stands and forbids only recommending a library switch.
- **Test 4** — a draw package that does not exist. Reviewer runs on 2026-11-09 (PR #186) had with-skill answers recommend `@maplibre/maplibre-gl-draw`, which npm does not have, and the judge passed them. `not-icontains: '@maplibre/maplibre-gl-draw'` now catches that name, and the skill never mentions it. It does not catch `@maplibre/mapbox-gl-draw`, the invented name in the with-skill answer above.
- **Test 5** — an older MapLibre the judge lets through. Graded again five times each, the two stored answers that offered `npm install maplibre-gl@1` passed 8 of 10 times ([CSV](latest/maplibre-mapbox-migration-test5-graded-again_2026-11-24.csv)). `not-regex: 'maplibre-gl@[\^~]?[1-3]\b'` now fails a `maplibre-gl` install or CDN pin from before v4.0.0, where the callback still worked, and the skill names none.

Passes are on the rubric's terms; the with-skill answers add unchecked claims outside them:

- Test 1 invents validator output and a `sky-type` key.
- Test 2 invents OpenFreeMap `outdoors` and `satellite` styles.
- Test 3 calls `sky` a layer.
- Test 4 recommends `@maplibre/mapbox-gl-draw` and `@maplibre/terra-draw` (both 404 on npm; Terra Draw is `terra-draw`) and describes the draw fix as editing the stylesheet, not overriding the class constants.

A reviewer's run of the same config on 2026-11-09 (PR #186) passed 6 of 7 and failed test 3 on invented `sky` keys, so one passing run of test 3 is not conclusive.
